Kaise use karein:
  1. Upar form bharein. Neeche code aur photo-naam apne aap ban jayenge.
  2. Step 1 ka code copy karke GitHub par index.html mein, aakhri product card ke baad paste karein.
  3. Step 2 ka code copy karke products.js mein, aakhri line ke end mein comma lagakar, uske neeche paste karein (file ke sabse end wale }; se pehle).
  4. Step 3 mein jo naam dikhein, unhi naam se apni photos assets folder mein upload karein.
  5. GitHub par Commit changes dabayein aur site par Ctrl+F5 dabakar check karein.
